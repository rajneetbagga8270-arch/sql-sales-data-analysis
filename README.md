# SQL Sales Data Analysis

## Project Overview

This project analyzes sales data using MySQL to identify revenue trends, product performance, customer behavior, and regional performance.

## Tools Used

- MySQL
- SQL
- JOINs
- Aggregate Functions
- CTEs
- Window Functions

## Dataset

The dataset contains 500 sales transactions from 2025.

## Project Workflow

1. Created and imported the raw sales dataset
2. Cleaned missing and inconsistent data using SQL
3. Created an analytical sales view
4. Calculated business KPIs
5. Analyzed revenue by region, product, category, and month
6. Used JOINs for customer analysis
7. Used CTEs for advanced analysis
8. Used window functions for ranking and trend analysis

## Key Analysis

- Total revenue
- Total orders
- Total customers
- Units sold
- Average order value
- Revenue by region
- Revenue by product
- Revenue by category
- Top customers
- Monthly revenue
- Month-over-month growth
- Product ranking
- Top product in each region
